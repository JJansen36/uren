Uren- en Kilometerregistratie Web App

INHOUD:
- Web app voor meerdere gebruikers
- Handmatige urenregistratie per project
- Kilometerregistratie (privé auto, per rit)
- Declaratiestatus voor uren en kilometers
- Weekoverzicht + PDF export
- Supabase backend

INSTALLATIE:
1. Maak een Supabase project aan
2. Run schema.sql in Supabase SQL editor
3. Vul config.js met je Supabase URL + anon key
4. Host deze map statisch (GitHub Pages / Netlify / lokaal)

PDF EXPORT:
Open report.html → Print → Opslaan als PDF
